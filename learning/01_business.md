## なぜこれを学ぶか

製造DXは「現場を便利にする」ことではない。  
**顧客価値と経営価値を継続的に生む仕組みを作ること**。  
この文脈なしに個別施策を始めると、「ツール導入したが何も変わらない」に終わる。

---

## 1. 顧客価値の構造

大型設備・産業機械における顧客価値の5軸：

| 価値軸 | 意味 | 製造側での影響 |
|--------|------|--------------|
| **安定稼働** | 納入後に止まらない | 品質・耐久設計・検査精度 |
| **省エネルギー** | 電力・熱コスト削減 | 設計仕様・加工精度 |
| **CO₂削減** | 排出量目標達成 | 設計・材料選定・工程選択 |
| **保全性** | 壊れにくく直しやすい | 部品供給・図面の明確さ |
| **TCO低減** | 初期費＋維持費の総合最小化 | 納期・品質・アフターコスト |

> **重要：** 顧客は「製品」にお金を払うのではなく、**製品を使った結果**にお金を払う。

---

## 2. TCO（Total Cost of Ownership）の構造

```
TCO = 初期費用
    + 運用費（エネルギー・消耗品）
    + 保全費（点検・部品交換）
    + 故障コスト（ダウンタイム損失）
    + 廃棄費用
    − 残存価値
```

### 製造品質とTCOの関係
- 加工精度が低い → 摩耗が早まる → 保全費↑ → TCO↑
- 納期遅れ → 顧客ラインの立ち上げ遅れ → 顧客TCO↑ → 次回失注

---

## 3. 製造部門と経営指標のつながり

```
製造現場の改善
  │
  ├─ 品質向上 → 不良返品・再作業コスト↓ → 粗利益↑
  ├─ 納期短縮 → 在庫・仕掛削減 → キャッシュフロー改善
  ├─ 設計変更迅速対応 → 顧客満足↑ → リピート受注↑
  └─ 設備稼働率向上 → 生産能力↑ → 売上機会↑
```

### 主要な経営指標

| 指標 | 定義 | 製造との関係 |
|------|------|------------|
| 売上総利益（粗利） | 売上 − 製造原価 | 材料費・加工費・不良コストに直結 |
| 仕掛在庫 | 製造途中の資産 | 長LTほど増大。設計変更で陳腐化リスク |
| 製品在庫 | 完成品の資産 | 個別受注では基本ゼロが理想 |
| キャッシュ転換サイクル | 原材料→現金化の日数 | LT短縮＝資金効率化 |
| 再作業コスト率 | 再作業工数÷総工数 | 品質管理の効果測定に直結 |
| 品質損失 | クレーム・返品・手直し費用 | 設計品質・製造品質・検査精度に比例 |

## 4. 製造DXと経営価値の接続

| DX施策 | 現場の変化 | 経営指標への影響 |
|--------|----------|----------------|
| 設計変更管理の整備 | 漏れ・手戻りが減る | 再作業コスト↓、納期遵守率↑ |
| 品質記録のデジタル化 | 異常の早期検出 | 不良コスト↓、クレーム↓ |
| 設備状態の見える化 | 予防保全が可能になる | 計画外停止↓、稼働率↑ |
| BOM整備 | 情報の一元管理 | 二重入力↓、設計変更の展開速度↑ |
| KPI可視化 | 経営判断の根拠が明確になる | 投資対効果の説明力↑ |

---

## 5. 重要概念：見込み生産 vs 受注生産

| 項目 | 見込み生産（MTS） | 受注生産（MTO/ETO） |
|------|-----------------|-------------------|
| 生産タイミング | 需要予測に基づく | 受注後 |
| 在庫 | 持つ | 原則ゼロ |
| 標準化 | 高い | 低い（個別仕様） |
| 設計変更 | 影響小 | 影響大（LT中に変更頻発） |
| 管理の難しさ | 需要予測精度 | 変更管理・納期管理 |
