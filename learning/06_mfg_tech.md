## 1. 工程設計の基礎

### 1.1 工法選定の考え方

```
加工方法の分類：
  除去加工：切削・研削・放電加工（EDM）・レーザー
  付加加工：溶接・メッキ・塗装・積層造形（AM/3D印刷）
  変形加工：プレス・鍛造・鋳造・押出し

選定基準：
  ① 必要精度（寸法公差・表面粗さ）
  ② 材料の加工性
  ③ 生産量（少量→汎用設備、大量→専用設備）
  ④ コスト（設備・工具・工数）
  ⑤ 設備能力（社内 or 外注）
```

### 1.2 加工ばらつきの理解

```
ばらつきの原因（4M）：
  Man（人）：スキルの差、疲労
  Machine（機械）：熱変位、振動、工具摩耗
  Material（材料）：硬度ばらつき、残留応力
  Method（方法）：段取り誤差、測定誤差

ばらつきの管理：
  公差（許容差）= ばらつき範囲に余裕を持たせた範囲
  工程能力（Cp/Cpk）でばらつきが公差内に収まるか評価
```

### 1.3 組立公差（公差積み上げ）

```
複数の部品を組み合わせると、各部品の寸法誤差が積み重なる

例：A（±0.1mm）+ B（±0.1mm）+ C（±0.1mm）
   最悪ケース積み上げ：±0.3mm
   統計的積み上げ：約±0.17mm（RSS法）

設計者は「組立後の最終寸法」が機能を満たすよう、
各部品の公差を配分して設計する（公差設計）
```

## 2. 治工具の役割

### 2.1 治工具とは

```
治具（Jig）：工作物を固定・位置決めする道具
工具（Tool）：切削・成形などを行う道具

治工具の目的：
  ① 位置決め精度の確保（誰が作業しても同じ位置に固定）
  ② 作業効率の向上（段取り時間の短縮）
  ③ 品質の安定化（人によるばらつきの排除）
  ④ 安全確保（危険な作業を機械化）
```

### 2.2 治工具管理

```
管理すべき情報：
  ① 治工具番号・名称
  ② 対応する品番・工程
  ③ 最終点検日・次回点検予定日
  ④ 使用回数（工具寿命管理）
  ⑤ 交換部品の在庫状況
  ⑥ 格納場所
```

## 3. 設備能力の理解

### 3.1 設備の基本仕様確認

```
確認すべき項目：
  加工範囲（ワークサイズの最大値）
  位置決め精度（繰り返し精度）
  主軸回転数・送り速度の範囲
  最大加工力（切削力）
  熱変位特性（温度による精度変化）
```

### 3.2 段取りの重要性

```
段取り：次の品種の加工を始めるための準備作業
  外段取り：加工停止せずにできる準備
  内段取り：加工停止中にしかできない作業

SMED（Single Minute Exchange of Die）：
  段取り替えを10分以内にする改善手法
  外段取りに転換できる作業を増やすことが基本
```

## 4. 測定誤差の理解

### 4.1 測定器の選定基準

```
精度の目安：
  測定器の分解能 < 測定対象の公差の 1/10

例：公差 ±0.1mm の場合
  → 分解能 0.01mm のノギスではギリギリ
  → 分解能 0.001mm のマイクロメータが適切
```

### 4.2 温度の影響

```
金属は温度で膨張する（線膨張係数）
鉄鋼：約12μm/m・℃

例：1m の鉄の部品が 10℃ 変化すると
  → 0.12mm 変化する

精密測定は 20℃ ± 1℃ の環境で実施が基本
```
