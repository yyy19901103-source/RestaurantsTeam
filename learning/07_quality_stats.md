## なぜこれを学ぶか

感覚ではなく**事実と数値**で異常を捉え、原因を切り分け、管理条件へ落とす。  
「なんとなく良くなった」では再発を防げない。数値で語れることが前提。

## 1. 統計の基礎

### 1.1 平均・標準偏差・分布

```
平均（μ）：データの中心
標準偏差（σ）：ばらつきの大きさ

正規分布では：
  μ ± 1σ の範囲にデータの 68.3% が入る
  μ ± 2σ の範囲にデータの 95.4% が入る
  μ ± 3σ の範囲にデータの 99.7% が入る

製造品質では「3σ」を不良品発生の境界として設定することが多い
```

### 1.2 ばらつきの2種類

| 種類 | 名称 | 特徴 | 対処 |
|------|------|------|------|
| **偶然原因** | 固有ばらつき | 工程が安定していても発生。排除不可能 | 許容範囲の設計で対応 |
| **異常原因** | 特殊原因 | 工具摩耗・設備異常・材料変化など | 検出→除去→再発防止 |

## 2. 工程能力指数：CpとCpk

### 2.1 Cp（工程能力）

```
          USL − LSL
Cp = ─────────────────
              6σ

USL：規格上限（Upper Specification Limit）
LSL：規格下限（Lower Specification Limit）
6σ：工程のばらつき幅

解釈：
  Cp < 1.00：工程能力 不足（不良品が出る可能性大）
  Cp = 1.00：工程能力 最低限（3σ以上でギリギリ）
  Cp ≥ 1.33：工程能力 十分（一般的な合格基準）
  Cp ≥ 1.67：工程能力 優秀（厳しい品質要求に対応）
```

### 2.2 Cpk（偏り考慮の工程能力）

```
Cpkは「平均が規格の中心からずれている場合」の能力指数

Cpk = min(Cpu, Cpl)

       USL − μ           μ − LSL
Cpu = ─────────   Cpl = ─────────
          3σ                3σ

CpとCpkの違いの例：
  Cp = 1.5（ばらつきは小さい）だが Cpk = 0.8（中心がずれている）
  → 工程のセンタリング（調整）が必要
```

### 2.3 実務での目安

| 要求 | Cp・Cpk基準 |
|------|------------|
| 一般部品 | ≥ 1.33 |
| 重要寸法・安全部品 | ≥ 1.67 |
| 医療・航空部品 | ≥ 2.00 |

## 3. 管理図（Control Chart）

### 3.1 管理図の目的
「工程が安定しているか」をリアルタイムで監視する。  
→ 異常を**不良が出る前に**検出する（予防管理）

### 3.2 X̄-R管理図（最も基本的な管理図）

```
上方管理限界（UCL）：─ ─ ─ ─ ─ ─ ─
                  ●        ●
中心線（CL）：  ────●─────────●─────
          ●                       ●
下方管理限界（LCL）：─ ─ ─ ─ ─ ─ ─

管理限界内＝正常　　管理限界外＝異常原因あり → 調査要
```

### 3.3 異常判定ルール（Westernルール等）

| ルール | 判定条件 | 意味 |
|--------|---------|------|
| ルール1 | 1点が管理限界外 | 明らかな異常 |
| ルール2 | 連続9点が中心線の同側 | 平均のシフト |
| ルール3 | 連続6点が単調増加/減少 | トレンド（工具摩耗など） |
| ルール4 | 連続14点が交互に上下 | 2系統の混在 |

## 4. MSA（Measurement System Analysis）/ GRR

### 4.1 なぜ測定誤差を評価するか
「測定値が規格内」でも**測定器や測定者が原因でデータがずれている**可能性がある。  
「製品のばらつき」なのか「測定のばらつき」なのか区別が必要。

### 4.2 GRR（Gauge Repeatability and Reproducibility）

```
全ばらつき = 製品ばらつき + 測定システムばらつき

測定システムばらつき = 繰返し性（Repeatability）+ 再現性（Reproducibility）

繰返し性：同じ人が同じ器具で同じ品物を測定した場合の差
再現性  ：異なる人が同じ器具で同じ品物を測定した場合の差
```

### 4.3 GRR判定基準

| GRR（%） | 判定 |
|---------|------|
| < 10% | 優秀：測定システムは適切 |
| 10〜30% | 条件付き許容：改善が望ましい |
| > 30% | 不適切：測定システムの見直し必須 |

## 5. 根本原因解析（Root Cause Analysis）

### 5.1 5 Whys（なぜなぜ分析）

```
問題：製品の穴径が規格外になった

なぜ①：ドリルの摩耗が進んでいた
なぜ②：交換時期を超えて使い続けた
なぜ③：交換基準（加工回数）を定めていなかった
なぜ④：工具寿命の管理ルールがなかった
なぜ⑤：工具管理の手順書自体がなかった

→ 根本原因：工具管理手順書の不整備
→ 対策：工具管理手順書の作成・遵守の仕組み化
```

### 5.2 特性要因図（フィッシュボーン）

```
問題（特性）←─────────────────── 
              ├─ Man（人）：スキル・手順理解
              ├─ Machine（機械）：精度・保全状態
              ├─ Material（材料）：材質・寸法ばらつき
              ├─ Method（方法）：工法・手順
              ├─ Measurement（測定）：測定誤差
              └─ Mother Nature（環境）：温度・湿度・振動
```

## 7. 統計解析の応用：異常検知

### 古典的手法
- 管理図：UCL/LCL逸脱の検出
- 外れ値検定：Grubbs検定、ESD法

### 近代的手法（参考）
- 機械学習ベースの異常検知（Isolation Forest、Autoencoder）
- 多変量管理図（T²管理図）：複数の品質特性を同時監視
